# MEGA CREATOR AI

AI Creator Studio для Android: единая мобильная студия для блогеров и создателей контента.
**Java + Android Studio + Gradle**, минимальный SDK 23, интерфейс на русском языке,
дизайн «чёрный / фиолетовый / синий», нижняя навигация из пяти вкладок.

> Всё для блогеров. Всё для творчества. Всё в одном приложении!

## Статус: всё бесплатно

Все инструменты открыты без оплаты и подписки; дневные лимиты — 100 000 на каждый инструмент.
Тарифы FREE/PRO/PREMIUM оставлены только как метки — доступ у них одинаковый.

| Локальный режим (без сервера) | Серверный режим (после входа) |
|---|---|
| AI-Студия: шаблонный генератор текстов, идей, сценариев, рекламы, хештегов и планов | Бесплатный ИИ через публичные API без ключей |
| Озвучка через системный TTS, сохранение WAV | Озвучка остаётся на устройстве |
| Шаблоны: редактирование, предпросмотр и экспорт PNG через Canvas | Шаблоны остаются локальными |
| Подготовка запросов для AI-ФОТО и AI-ВИДЕО | AI-фото генерируется бесплатно; AI-видео требует `VIDEO_*` на сервере |
| Проекты, избранное, история, дневные лимиты | Проекты можно отправлять на сервер; лимиты проверяет сервер |
| FREE/PRO/PREMIUM — весь функционал доступен | Вход по коду (телефон/email), оплата не нужна |

Локальный генератор **не является нейросетью**: он создаёт заготовки по шаблонам и работает
офлайн. Серверные вызовы идут вне UI-потока через `ServerGateway.java`; ключи API хранятся
только на сервере, в APK их нет.

## Экраны

- **Главная** — логотип, аватар, уведомления, статус тарифа, кнопка «Создать с ИИ»,
  карточки инструментов, остаток лимитов и последние проекты.
- **AI-Студия** — выбор инструмента, ввод темы/аудитории/преимущества, генерация
  (через сервер после входа), копирование результата и сохранение в проект.
- **Шаблоны** — сторис, обложки, баннеры, поздравления, мотивация, пост для Telegram;
  редактирование текста, предпросмотр и сохранение готового PNG (`TemplateRenderer.java`).
- **Проекты** — фильтры (все / тексты / реклама / шаблоны / озвучка / избранное),
  просмотр, копирование, удаление.
- **Профиль** — вход по коду (телефон/email), имя/email/телефон, тарифы (все бесплатны),
  дневные лимиты, адрес сервера, переключатель темы, помощь, удаление данных.
- Подэкраны: **AI-ФОТО** и **AI-ВИДЕО** (подготовка запроса, генерация на сервере,
  просмотр и сохранение результата), **Озвучка AI**, редактор шаблона с экспортом PNG,
  проект с отправкой на сервер.

## Доступ и тарифы

| Тариф | Цена | Возможности |
|---|---|---|
| FREE | 0 ₽ | Все инструменты ИИ, тексты, фото, видео, озвучка, шаблоны |
| PRO | 0 ₽ | То же |
| PREMIUM | 0 ₽ | То же |

Оплата, ЮKassa и демо-режим больше не нужны: выбор тарифа просто меняет метку в интерфейсе.
Лимиты заданы в `Limits.java` и `server/lib/limits.js` — 100 000 генераций в день на инструмент.
Сервер всё равно проверяет лимиты до вызова провайдера и списывает только после успеха.

## Безопасность

- Никаких ключей ИИ, платёжных или серверных секретов в APK нет: они читаются сервером из env.
- Адрес сервера и токен сессии хранятся в `SharedPreferences` и вводятся пользователем.
- Права и лимиты проверяются на сервере; платежи в приложении не используются.
- Коды входа хранятся на сервере как SHA-256; `DEV_MODE` нужен только для локальной разработки.
- Есть удаление аккаунт-данных и всех проектов кнопкой в Профиле (`DELETE /api/account`).
- Для публичного сервера нужны HTTPS и базовый rate limiting внешнего провайдера.

## Сборка APK

Локально нужен Android Studio (Java 17, Android SDK 35, Gradle 8.9). Без SDK можно сборкой
через GitHub Actions — она уже настроена в `.github/workflows/build-apk.yml`.

```bash
# в Android Studio: Open existing project → папка MegaCreatorAI
# или в терминале с установленным SDK/Gradle:
gradle assembleDebug
gradle test
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
При пуше в `main` workflow публикует APK в Releases как `build-N`.

### Сервер

Сервер на Node.js 18+ без npm-зависимостей. Переменные окружения и примеры запросов —
в `server/README.md`. Минимальный запуск для разработки:

```bash
cd server
DEV_MODE=true npm start
# в Профиле приложения: http://<host>:3000 → «Получить код» → «Войти»
# DEV_MODE показывает код прямо в приложении; в продакшене нужен CODE_WEBHOOK_URL
```

Бесплатные ИИ-текст и AI-фото работают без ключей: сервер использует публичные
`text.pollinations.ai` и `image.pollinations.ai`. При желании задайте свои `AI_*`/`IMAGE_*`.
Для AI-видео задайте `VIDEO_*` (бесплатный ключ Pollinations можно получить в аккаунте).
`GET /api/config` показывает, что настроено, без ключей.

## Юнит-тесты

`LocalAiTest`, `LimitsTest` и `ApiToolsTest` проверяют генератор, тарифы и соответствие
названий инструментов серверному API без Android-эмулятора:

```bash
gradle test
```

## Структура

```
app/src/main/java/com/megacreatorai/
  MainActivity.java    — вкладки, подэкраны, серверные вызовы, профиль, TTS
  LocalAi.java         — локальный шаблонный генератор контента
  Limits.java          — все тарифы бесплатны, лимиты 100 000 (совпадают с серверными)
  ProjectStore.java    — SharedPreferences: проекты, история, профиль, токен, Usage
  ServerGateway.java   — HTTP-шлюз (GET/POST/DELETE + Bearer-токен)
  ApiTools.java        — соответствие инструментов и контактов контракту API
  ApiCallback.java     — асинхронный колбэк без java.util.function
  MediaLoader.java     — загрузка изображения из URL или data URL
  TemplateRenderer.java — локальный рендер шаблонов в PNG через Canvas
  Ui.java              — единый стиль карточек, кнопок, полей и диалогов
app/src/main/res/      — XML-тема, цвета, layout, меню, адаптивная иконка и PNG 96×96
app/src/test/java/     — юнит-тесты на чистом Java
server/server.js        — маршруты HTTP-сервера
server/lib/             — config, auth, limits, providers, payments, store, http, util
server/schema.sql       — справочная схема PostgreSQL (для multi-instance)
server/README.md        — переменные окружения и примеры curl
```

## План дальше

1. Поднять сервер с `DEV_MODE=true` и бесплатными провайдерами, проверить вход по коду.
2. При желании добавить `VIDEO_*` для AI-видео и `CODE_WEBHOOK_URL` для получателей кодов.
3. Заменить JSON-хранилище на PostgreSQL при нескольких инстансах сервера.
4. Протестировать на устройствах, сделать release-сборку и подписать APK.

Важно: генерация зависит от внешних API, интернета и их правил; «бесплатно» означает отсутствие
оплаты внутри приложения. Публичные провайдеры могут изменять лимиты и условия доступа.
